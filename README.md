## 🧰 What I can do

### AI & Interpretability
**J-Lens** – Interactive sparse transformer interpretability dashboard. Precomputes J-Space Jacobians offline, then lets you generate text and click any token to see its semantic representation across layers — with OMP sparse decomposition and activation interventions (steer / swap / ablate). Python + TransformerLens + Gradio.
- Designed and built entirely by me: Jacobian precomputation, sparse solvers, per-token layer analysis, interactive UI.

→ [View project](https://github.com/tsepokfun/j-lens)

### AI & Multi-Agent Systems
**Gennerative-Object** – A dynamic multi-agent social meta-simulation platform. Type one natural-language sentence (e.g. "simulate the impact of a night-market noise policy"), and it generates agents calibrated to real HK population data, runs a LangGraph simulation, and outputs structured policy reports.
- LangGraph + DeepSeek + ChromaDB, data.gov.hk pipeline, WebSocket live dashboard. HKICT 2026 submission.

→ [View project](https://github.com/tsepokfun/Gennerative-Object)

**AI Web Dev Workspace** – A next-gen AI web development workstation built around a **Code Segment Tree**: one semantic index of your whole project, scope-constrained editing (necessary change only), compile-verified updates, git-baseline retry loops, and a human-in-the-loop permission explainer.
- TypeScript + web-tree-sitter + Node.js, with a vanilla-JS web UI, LLM-driven navigation and reviewing. *(In development — public soon.)*
